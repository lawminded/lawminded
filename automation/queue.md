# Requested topics

Topics the owner asked for by name, waiting to be written. The weekly run reads
this before it researches anything, and takes from here first — a topic the owner
named beats anything the run would find on its own.

This file is committed to git, so a request survives the process that recorded it.
That is the whole point: a reminder held in a running program lasts only as long
as the program, which is seconds.

Format, one entry per line:

    - [ ] YYYY-MM-DD | topic     write it on or after that date
    - [ ] any        | topic     write it on the next run, whenever that is

Tick the box once written and leave the line in place, with the date it went out.
The history of what was asked for is worth keeping.
